# Kagura

**Kagura** is a standalone anime & manga tracking app for Android, forked from and built on top of [Dantotsu](https://github.com/rebelonion/Dantotsu) (which itself grew out of Saikou). It's an AniList-first client that can also hook into extensions for streaming/downloading anime and reading manga.
